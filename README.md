# Open Course Space – Converted to Docsify-This

> The example course CPT363-1 from the [Grav Open Course Space skeleton](https://github.com/hibbitts-design/grav-skeleton-open-course-space), converted to plain Markdown pages for [Docsify-This](https://docsify-this.net/#/) by the [Open Publishing Course Hub Converter](https://open-publishing-course-hub-converter.hibbittsdesign.org).

View it as a website: https://docsify-this.net/?basePath=https://raw.githubusercontent.com/paulhibbitts/docsify-this-open-course-space-site/main&homepage=home.md&sidebar=true&loadSidebar=_sidebar.md&loadNavbar=_navbar.md&loadFooter=_footer.md&pagination=true&searchbox=true&name=CPT363-1

These pages are the converter's output as it is, laid out like the [Docsify Open Course Starter Kit](https://github.com/hibbitts-design/docsify-open-course-starter-kit) and shown like the course in Open Course Space: the home page starts with the course's header image and name, the sidebar lists the modules and the LMS links, the navbar has the course pages, and Previous/Next buttons follow the modules in order.

The original course is built with Grav Open Course Space at https://demo.hibbittsdesign.org/grav-open-course-space – this version uses the same content:

- `home.md` – the course home, with this week's reminders and what's coming next week
- `welcome.md`, `module-01.md` … `module-13.md` – a page per module
- `schedule.md`, `resources.md`, `syllabus.md`, `contact.md` – the course pages in the navbar
- `images/` – the images used on the pages

Only the modules and the course pages are converted – the course's Read Me is about the Grav site, so it stays there.

Each page also keeps its Grav settings in a hidden note at the top, so the converter can turn these pages back into the same Open Course Space course folder.
